# 05 Ordering Experience

## Core User Flows
- Browse products
- Filter and search
- Add to cart
- Save favourites
- Modify quantities
- Checkout quickly
- Choose pickup or delivery
- Schedule time slot
- Add order notes
- Apply vouchers
- Track order status
- Receive confirmation

## Mobile Priority
- Mobile-first navigation
- Large tap targets
- Fast cart access
- Simplified checkout flow
- Sticky add-to-cart actions

## Checkout Requirements
- Guest checkout option
- Saved addresses
- Delivery or pickup selector
- Flexible time selection
- Voucher support
- Clear order confirmation
