# 06 Design System

## Colour Palette
- Primary Green: #5F8F4E
- Soft Sage: #DDE8D7
- Cream: #F7F2E8
- Charcoal: #2E2E2E
- Coral Accent: #F28C5C
- White: #FFFFFF

## Typography
- Display: Inter / Sora / Manrope
- Body: Inter
- Hierarchy: Bold headings, generous spacing, strong contrast

## Spacing System
- 4px base unit
- 8, 12, 16, 24, 32, 48, 64 spacing scale

## Grid
- 12-column layout on desktop
- 4-column layout on mobile

## Components
- Buttons
- Cards
- Inputs
- Forms
- Badges
- Modals
- Toasts
- Empty states
- Loading skeletons

## Accessibility
- WCAG AA contrast
- Focus states
- Keyboard-friendly navigation
- Semantic structure
- Screen-reader support

## Motion
- Gentle transitions
- Hover elevation
- Smooth section reveals
- Subtle product-card motion
